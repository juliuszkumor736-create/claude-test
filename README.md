# Claude Code Test Project

This is my Claude Code test project, used to verify that the Claude Code setup is working correctly.

## Purpose

The purpose of this project is to test and validate the Claude Code environment — confirming that Claude can inspect directories, create files, and execute code within a local project workspace.

## Claude Code Test

Ten projekt służy do testowania Claude Code w praktyce — sprawdzania integracji z Pythonem oraz workflow Git i GitHub (odczyt statusu repozytorium, edycja plików, przygotowywanie zmian do commita).
